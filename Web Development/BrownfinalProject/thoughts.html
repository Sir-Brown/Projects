Reflection

Research

Before I even typed a single line of html code, my first instruction was to do research on what needed to be done. This process was not too time consuming and very rewarding as it helped me gauge what I needed to do. Additionally, I made a page detailing the product of my research.

See: Research Page

Wireframes

Similar to the previous segment, before I wrote any html code, my next course of action was to create a wireframe. This process took more time than the last but it allowed me to visualize how I wanted my webpage to look. This is because a wireframe is an image which displays the functional elements of a website or page.

(Definition from Oxford Languages)

Creating the home page

Now it was finally time to start typing up some code. My first goal was to create a Home Page. This would act as a landing page for viewers and introduce me and my work. This process took more time than the last two as I not only had to bring my wireframe to life but I had to do so with HTML and CSS. Creating it was not too difficult, though. Most of the time spent was on making it compatible for mobile devices via the use of media queries.

See: Home Page

Fleshing out the website

After completing the home page, the next task was to flesh out the website. I added more pages and gave them all different layouts based on the content they housed. This phase of creating an ePortfolio took the most time as I had to create wireframes and then pages for four (4) additional pages, and on top of that, I had to make them mobile compatible. This part was more tedious due to the nature of CSS. I had to constantly use the inspection tool to see what lines of code were working and which weren't and why. More often than not another instance was being read first or a later instance was read and overwrote the previous one. However, I fixed this and it resulted in the completion of this phase.

Future

When it comes to my future I am uncertain, but what I do know, is that if I continue down this path, then the skills learned while making this ePortfolio will prove helpful. Not only that, but I can use this as ePortfolio to store and eventually show off my work in the future. This will allow me to show potential employers what I am capable of. Though, this is where my journey ends for this course, this is not where it ends with this website as I plan to either remake it entirely or upgrade it, possibly changing the design once I've become more advanced.
